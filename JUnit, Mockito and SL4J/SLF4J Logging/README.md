# SLF4J Logging Exercises

## Exercises

- Error Logging
- Warning Logging
- Parameterized Logging
- Multiple Appenders
- Logback Configuration

## Run

```bash
mvn compile exec:java
```

> To run a specific exercise, update `<mainClass>` in `pom.xml`:
> - `LoggingExample`
> - `ParameterizedLogging`
> - `AppenderLogging`
